Rowstead API

Import a spreadsheet, process its rows, and download the results.

OpenAPI JSON ↗

Authentication and CSRF

Sign in with POST /api/v1/auth/login using a JSON body containing login and password. Keep the returned session cookie for subsequent requests.

The login response includes csrf_token. Send it as X-CSRF-Token on every POST request after login. You can also read the current token from GET /api/v1/session. File uploads use multipart form data; other request bodies use JSON.

A typical workflow

  1. Sign in. POST /api/v1/auth/login
  2. Upload data. POST /api/v1/imports with multipart file. Save the returned import ID and inspect the preview.
  3. Create a task. POST /api/v1/tasks with name, import_id, adapter and mapping. Mapping connects processor fields to column names, for example {"identifier":"company_id"}.
  4. Start processing. POST /api/v1/tasks/{id}/start. Poll the task and its rows to see progress.
  5. Download results. GET /api/v1/tasks/{id}/export?format=csv or format=xlsx. Partial downloads include the current status of every row.

Included adapters: registry_demo and browser_demo. Requests and results are scoped to the signed-in account. Error responses include a message and a request ID when available.
